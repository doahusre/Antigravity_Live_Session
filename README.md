# Antigravity Live Session

Real-time, full-duplex conversational voice assistant with desktop vision, Niri window management, live Brain/HUD telemetry, and browser automation, powered by Gemini Live (`gemini-live-2.5-flash-native-audio`).

## One-Command Workspace Launch
Run `agy-live` (or `.agents/voice/launch_workspace.sh`) from any terminal to launch or restore the exact 3-pane workspace:
- **Top-Left (`iggnita:2.1`)**: Antigravity Lead Agent CLI (`agy`)
- **Top-Right (`iggnita:2.2`)**: Antigravity Live Brain & HUD (`antigravity_hud.py`)
- **Bottom (`iggnita:2.3`)**: Gemini Live Full-Duplex Voice Assistant (`gemini-live`)
- **Background Daemon**: Real-Time Watchdog (`watchdog.py`)
